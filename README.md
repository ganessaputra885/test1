# Inventory Sparepart

Aplikasi sederhana untuk mengelola stok sparepart dengan fitur:

- Menambah item sparepart
- Menampilkan daftar stok
- Mencari item berdasarkan nama atau SKU
- Filter kategori
- Update stok naik/turun
- Hapus item
- Statistik inventaris
- Penyimpanan data di browser menggunakan localStorage

## Cara menjalankan

1. Buka folder project.
2. Jalankan server lokal:

```bash
cd c:\test\test1
python -m http.server 8000
```

3. Buka browser ke:

```text
http://localhost:8000
```

## File utama

- `index.html` = tampilan aplikasi
- `style.css` = desain dan layout
- `app.js` = logika inventaris
